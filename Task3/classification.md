# Классификация данных и инструменты защиты

Стратегия защиты данных компании «Медикаменте» с учётом шифрования **at rest** (при хранении) и **in transit** (при передаче). Данные классифицированы по чувствительности и профилю риска: от публичной информации до специальных категорий ПДн (медицинские данные) и критичных секретов.

## Классификация данных

| Данные | В чём необходимость защиты | Инструменты защиты |
|--------|----------------------------|--------------------|
| **ФИО, дата рождения пациента** (Excel, БД, папки на файловом сервере) | Персональные данные по 152-ФЗ; идентифицируют субъекта; сейчас хранятся в открытом виде и в именах папок | **At rest:** шифрование дисков (BitLocker/LUKS), шифрование БД (PostgreSQL TDE/pgcrypto), AES-256 для файлового хранилища. **In transit:** TLS 1.2+ для веб-портала и API. **Контроль:** RBAC, аудит доступа, маскирование в логах |
| **Телефон, e-mail** | Контактные ПДн; при утечке — фишинг, спам; переписка в Outlook не контролируется | **At rest:** шифрование БД и почтового хранилища. **In transit:** TLS для API и веб-форм, S/MIME или TLS для Exchange. **Контроль:** DLP для исходящей почты, маскирование в UI (`+7***1234`) |
| **Адрес, место работы/учёбы** | ПДн; избыточный сбор повышает ущерб при утечке; хранятся в сканах анкет без структуры | **At rest:** шифрование файлового хранилища и БД. **In transit:** TLS. **Контроль:** минимизация данных (собирать только необходимое), ограничение доступа по роли |
| **Медицинские данные** (диагнозы, жалобы, хронические заболевания) | Специальная категория ПДн (ст. 10 152-ФЗ), медицинская тайна; максимальный правовой и репутационный риск | **At rest:** AES-256, отдельное хранилище для медкарт (MinIO/S3 с SSE), шифрование бэкапов. **In transit:** TLS/mTLS между МИС и сервисами. **Контроль:** разграничение доступа врач → свои пациенты, MFA, полный аудит просмотра |
| **Результаты анализов** (Excel `RegistryByDate`, файлы лаборатории) | Специальная категория ПДн; реестры на общем диске без связи с картой пациента | **At rest:** шифрование хранилища, перенос из Excel в защищённую БД. **In transit:** TLS/mTLS при интеграции с лабораторией. **Контроль:** API с проверкой прав, аудит выгрузок |
| **Записи на приём** (дата, врач, статус) | Связывают пациента с врачом и услугой; ПДн | **At rest:** шифрование БД. **In transit:** TLS. **Контроль:** RBAC по роли (ресепшен, врач), скрытие ФИО в общем журнале |
| **Финансовые данные пациентов** (оплаты, чеки, суммы) | ПДн + коммерческая информация; дублирование кассирами в Excel создаёт неконтролируемые копии | **At rest:** шифрование 1С и БД, отказ от Excel-дублей. **In transit:** TLS для платёжного шлюза и ККМ. **Контроль:** аудит операций, токенизация платёжных реквизитов |
| **Договоры и согласия на обработку ПДн** | Подтверждают законность обработки; содержат ПДн; хранятся произвольно на ресепшене | **At rest:** защищённое файловое хранилище с шифрованием, контроль срока хранения. **In transit:** TLS при электронной передаче. **Контроль:** привязка к карте пациента, аудит доступа |
| **Кадровые данные сотрудников** (паспорт, ИНН, СНИЛС, зарплата) | ПДн сотрудников; обрабатываются в 1С без отдельного контура | **At rest:** шифрование 1С и дисков, отдельные роли HR/бухгалтерия. **In transit:** TLS, VPN для удалённого доступа. **Контроль:** RBAC, аудит выгрузок |
| **Учётные записи, пароли, API-ключи** | Компрометация ведёт к доступу ко всем данным; секреты могут попасть в код | **At rest:** хеширование паролей (bcrypt/argon2), хранилище секретов (Vault). **In transit:** TLS, VPN. **Контроль:** MFA для администраторов, сканирование секретов в Git (Gitleaks), ротация ключей |
| **Метаданные файлов** (имена папок `Pacient-FIO-BD`) | Раскрывают ПДн без открытия файла; любой с доступом к диску видит ФИО | **At rest:** переименование в `patient-{UUID}`, шифрование диска. **In transit:** — . **Контроль:** сканер имён файлов, запрет PII в путях |
| **Логи приложений и аудита** | При ошибках могут случайно содержать ПДн и медданные | **At rest:** шифрование хранилища логов. **In transit:** TLS до SIEM. **Контроль:** маскирование полей, запрет логирования диагнозов и паспортных данных |
| **Бэкапы** (БД, файлы, 1С) | Содержат полный массив ПДн; один незашифрованный бэкап = полная утечка | **At rest:** шифрование бэкапов AES-256, ключи отдельно от копий. **In transit:** TLS/VPN при передаче в удалённое хранилище. **Контроль:** регулярная проверка восстановления, ограничение доступа |
| **Данные для BI/аналитики** (Excel в Jupyter) | Сырые ПДн в аналитике — риск массовой утечки; бизнес-аналитик работает без обезличивания | **At rest:** шифрование data lake, доступ только к обезличенным витринам. **In transit:** TLS. **Контроль:** обезличивание/псевдонимизация перед загрузкой в ClickHouse, запрет прямого доступа к raw PII |

## Автоматизированный контроль

| Контроль | Инструмент | Что проверяет |
|----------|------------|---------------|
| Сканирование секретов в коде | Gitleaks / TruffleHog | API-ключи, пароли в репозиториях |
| Проверка TLS | cert-manager, мониторинг сертификатов | Срок действия сертификатов, версия TLS |
| Аудит доступа | Elastic / SIEM | Нетипичный просмотр карт, массовые выгрузки |
| Контроль утечек | DLP | Отправка ПДн по почте, копирование на USB |
| Сканирование файлов | Purview / ручной аудит файлового сервера | PII в именах файлов, неучтённые Excel-копии |
| Проверка бэкапов | Backup audit | Шифрование, успешное восстановление |

## Реестр программных и аппаратных средств защиты

| Средство | Тип | Назначение |
|----------|-----|------------|
| BitLocker / LUKS | ПО | Шифрование дисков серверов и рабочих станций |
| PostgreSQL TDE / pgcrypto | ПО | Шифрование данных в БД (CRM, МИС) |
| MinIO / S3 SSE | ПО | Шифрование медицинских файлов (PDF/JPG) |
| TLS / cert-manager | ПО | Защита данных при передаче (HTTPS, API) |
| VPN | ПО/аппаратное | Безопасный удалённый доступ сотрудников |
| HashiCorp Vault | ПО | Хранение ключей шифрования и секретов |
| Active Directory + RBAC | ПО | Разграничение доступа по ролям |
| DLP | ПО | Контроль утечек через почту и файлы |
| Gitleaks | ПО | Поиск секретов в коде (CI/CD) |
| Elastic / SIEM | ПО | Централизованный аудит и алерты |
| Межсетевой экран (NGFW) | Аппаратное | Сегментация сети, контроль потоков |
| HSM / TPM | Аппаратное | Защита мастер-ключей шифрования |
| MFA-токены | Аппаратное | Усиленная аутентификация администраторов и врачей |
